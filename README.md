# Sagnik — Creative Developer & Visual Designer

An experimental, high-craft personal portfolio showcasing brand experiences, digital ecosystems, and creative direction.

## Features

- **Interactive Canvas & Fluid Smoke Simulation**: Custom canvas-based particle smoke dynamics reactive to cursor movement and scroll velocity.
- **Procedural Ambient Soundscape**: Web Audio API-powered generative soundscape with interactive frequencies and audio feedback toggles.
- **Curated Selected Works**: Interactive project showcases featuring modal case studies with detailed technical highlights.
- **Glassmorphic & Brutalist Aesthetics**: Neon yellow accents, deep matte obsidian backgrounds, fluid typography, and bespoke micro-interactions.
- **Interactive Terminal & Form Validation**: Real-time form feedback and dynamic interactive elements.

## Tech Stack

- **Core**: Vanilla JavaScript (ES Modules), HTML5, CSS3
- **Graphics & Audio**: HTML5 Canvas 2D API, Web Audio API
- **Build & Dev Tooling**: [Vite](https://vitejs.dev/)

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

```bash
# Clone the repository
git clone https://github.com/sagnikishere/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Vite development server
npm run dev
```

### Building for Production

```bash
npm run build
```
